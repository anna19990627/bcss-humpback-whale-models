# Humpback whale modelling code

R code for the humpback whale analyses associated with the BCSS surveys in the Bazaruto Archipelago, Mozambique.

## Contents
- `scripts/occurrence_sdmTMB_revised.R`
- `scripts/behaviour_brms_revised.R`
- `scripts/group_cohesion_brms_revised.R`

## Data availability
The raw and intermediate data are not included in this repository.

## Notes
The scripts use local file paths and expect project-specific input data to be available on the user's machine.
